# MiamMiam Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Proposer chaque samedi un plan de 14 repas, le faire valider, le publier sur GitHub Pages et envoyer chaque lundi la liste de courses et l'image de la semaine.

**Architecture:** Deux tâches planifiées de Claude Desktop génèrent le contenu et appellent une CLI Node. La CLI contrôle les plans, calcule la liste, produit le site et l'image, publie puis envoie l'email avec `gws`. Tout l'état vit dans des fichiers JSON par semaine.

**Tech Stack:** Node 25 (ESM), `node:test`, `playwright-core` avec le Chrome installé (`channel: "chrome"`), `gws`, `git`, `gh`, GitHub Actions et Pages.

**Spec:** `docs/superpowers/specs/2026-11-01-miammiam-design.md`

## Global Constraints

- Interface, emails et site en français.
- Aucune adresse email, aucun identifiant ni jeton dans un fichier versionné. Le dépôt est public.
- `playwright-core` est la seule dépendance npm.
- Dépôt : `roromaster/miammiam`, public. URL : `https://roromaster.github.io/miammiam/`.
- Toute page porte `<meta name="robots" content="noindex">`.
- Chaque message de commit se termine par la ligne d'attribution `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

**Précision par rapport à la spec :** les plans `proposed` sont dans `data/proposals/<semaine>.json` (exclu de git) et passent dans `data/weeks/<semaine>.json` à la validation. C'est ce qui garantit qu'une proposition n'est jamais poussée (spec, section 8).

## Review Focus

1. Titre avec caractères spéciaux (`Bœuf & carottes <maison>`) : échappé dans le HTML, et objet d'email encodé correctement.
2. Titre très long dans l'image : texte entier visible, sans débordement de la case.
3. Tâche relancée, en retard, ou à cheval sur deux années (semaine 2026-W53) : bonne semaine ciblée, sans double envoi.
4. Variantes d'ingrédients (`Oignon ` et `oignon`, `500 g` et `1 kg`, `0.1 + 0.2`) : une seule ligne et un total propre.
5. Fichier de destinataires absent ou vide : erreur claire, sans publication ni envoi partiel.
